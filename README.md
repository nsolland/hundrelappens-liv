# Hundrelappens liv

Interaktiv demonstrasjon av norske pengestrømmer, prisstigning og kjøpekraft. Modellen er eksplisitt forenklet og er ikke en prognose, et nasjonalregnskap eller skatterådgivning.

Kilde: nsolland/hermes-unlimited-dev, experiments/hundrelappens-liv (development).

Åpne index.html i nettleser. Ingen server eller avhengigheter kreves.

Begrensninger: faste og illustrative skattesatser; offentlig verdi, faktiske nasjonale data, atferdsendringer, gjeld og produktivitetsutvikling inngår ikke. Skatt, bedriftens kostnader og inflasjon skal ikke summeres som samme type tap.
